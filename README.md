📊 Social Media Impact on Students — EDA

📌 Project Overview

This project uses Exploratory Data Analysis (EDA) to investigate how social-media usage is associated with students' academic performance, sleep, mental health, and overall impact.

The analysis uses Python to explore patterns, relationships, and correlations within the dataset.

🎯 Research Question

«How is social-media usage associated with academic performance, sleep, mental health, and overall impact among students?»

📂 Dataset

The dataset contains information about students and their social-media usage.

Dataset Information

- Rows: 1,705
- Columns: 11
- Missing values: 0
- Complete duplicate rows: 0

Main Variables

- "Avg_Daily_Usage_Hours" — Average daily social-media usage
- "Most_Used_Platform" — Most-used social-media platform
- "Affects_Academic_Performance" — Whether social media affects academic performance
- "Sleep_Hours_Per_Night" — Sleep hours per night
- "Mental_Health_Score" — Mental-health score
- "Overall_Impact" — Overall impact of social media

📈 Key Findings

1. Social-Media Usage

The average daily social-media usage in the dataset is approximately 5.1 hours.

2. Sleep

Higher social-media usage is associated with fewer hours of sleep.

3. Mental Health

Social-media usage and mental-health score have a strong negative correlation of approximately -0.83.

This means that higher usage is associated with lower mental-health scores in this dataset.

4. Academic Performance

Students whose records indicate that social media affects academic performance have higher average daily usage than the group reporting no effect.

- No: approximately 4.07 hours
- Yes: approximately 5.81 hours

5. Overall Impact

The negative-impact group has higher average social-media usage and lower average mental-health scores compared with the positive-impact group.

⚠️ Limitations

This dataset is about social-media usage, not AI usage.

The dataset does not contain:

- AI usage
- AI usage time
- Addiction score
- GPA or actual grades
- Date/time information

Therefore, AI-specific questions cannot be directly answered using this dataset.

Also, correlation does not prove causation. The findings represent associations observed in this dataset.

📝 Conclusion

The analysis found consistent associations between higher social-media usage and fewer sleep hours, lower mental-health scores, and a higher reported academic-performance impact.

However, these results do not prove that social-media usage directly causes these outcomes.
